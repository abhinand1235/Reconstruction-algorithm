# Mini-JAXus Project Progress

This repository contains the progress and implementation work done so far for the ultrasound simulation project.

## Work Completed

- Started building the ultrasound simulation framework.
- Implemented the initial wave propagation model.
- Created the tissue model environment.
- Added a simulated tissue region with a cyst structure.
- Started mapping the wave interaction with the tissue cells.
- Implemented the initial process for identifying cells affected by the propagating wave.

## Current Status

The basic simulation setup is completed. The next phase will focus on continuing the wave-tissue interaction model and developing the remaining ultrasound simulation components.

## Purpose

This repository is maintained to track the development progress and document the stages completed during the project.
